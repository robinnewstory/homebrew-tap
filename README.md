# robinnewstory/homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask robinnewstory/tap/tibber-menu-bar
```

The apps are signed but not notarized, so macOS asks you to allow them once under
System Settings → Privacy & Security ("Open Anyway"). Add `--no-quarantine` to the
install command to skip that step.

| Cask | App |
|---|---|
| `tibber-menu-bar` | [Tibber Menu Bar](https://robinnewstory.github.io/tibber-menu-bar/): your current Tibber electricity price in the menu bar. |
